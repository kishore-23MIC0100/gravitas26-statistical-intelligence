# graVITas '26 - Statistical Intelligence Dashboard

Press Interview & Authorized Media Briefing Analytics Dashboard for graVITas '26.

## Features
- **CSV Data Ingestion**: Client-side parsing and validation of event records.
- **Participation Mix**: Internal vs. External metrics and institutional distribution.
- **Registration Rankings**: Top events, category segmentation, and revenue insights.
- **Data Quality & Hygiene**: Automatic duplicate detection and schema validation.

## Tech Stack
- Next.js (App Router)
- React 19
- Tailwind CSS
- Vitest
- PapaParse & Zod

## Getting Started

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
